 # ⚙️ Data-Driven Expense & Financial Analytics Tracking System - Backend

A scalable, high-performance GraphQL API service built with NestJS and MongoDB to resolve complex financial queries, enforce secure role authorization, and manage transaction logs.

---

## ✨ Key Features

- 🚀 **Scalable GraphQL API** — Flexible schema layout avoiding data over-fetching and enabling efficient client querying.
- 🔒 **Secure Authorization** — Implements JWT authentication alongside custom NestJS Guards to safeguard transaction logs and user preferences.
- 🗄️ **Modular Schema Design** — MongoDB data modeling optimized for CRUD operations on income, expense logs, and aggregated summaries.
- 🏗️ **Clean Architecture** — Structured into modular NestJS services, resolvers, and custom middleware for code maintainability.

---

## 🛠 Tech Stack

- **Framework:** NestJS
- **API Layer:** GraphQL
- **Language:** TypeScript
- **Database:** MongoDB 
- **Security:** Passport-JWT, Bcrypt
